首个版本。

## 安装

1. 下载下面的 `search-and-rename-0.1.0.vsix`；
2. 在 VSCode 里按 `Ctrl+Shift+X` 打开扩展面板 → 点右上角 `…` → **从 VSIX 安装…** → 选中刚下载的文件；
3. 若没立刻生效：按 `Ctrl+Shift+P` 执行 `Developer: Reload Window`。

命令行安装（在 `.vsix` 所在目录执行）：

`code --install-extension search-and-rename-0.1.0.vsix`

## 这个版本能做什么

- **资源管理器右键批量重命名**：在文件/文件夹上右键 → 「批量重命名名称…」，
  作用范围就是你选中的那棵子树，不会去动整个工作区。
- **按目录分组的树形预览**：每个目录只出现一次；被改名的文件夹成为可折叠分组头，
  其整棵子树缩进挂在下面；只有一个条目的目录不开头，目录名降级成行内前缀。
- **新名优先**：一行放不下时旧名先让位（`ot_body_029.…`），
  新名——也就是你要提交的结果——始终完整可读。
- **冲突拦截**：目标已存在 / 批次内撞名 / 仅大小写变化 / 非法名称。
  冲突项**默认不勾选**，绝不静默覆盖，也不自作主张加序号。
- **一次撤销**：单次 `WorkspaceEdit` 提交，`Ctrl+Z` 整体回滚；
  另保留最近 20 次批量操作日志可逐次回滚。
- **替换语义**：区分大小写、全字匹配、正则、保留大小写、保留扩展名；
  支持 `$1`~`$99` 捕获组、命名捕获组、`$&`、匹配前/后文本、`$$`。

## 已知边界

- 不跟随符号链接（避免环与越界）。
- 大小写不敏感的文件系统上做「仅大小写改名」时，会提示 git 可能不识别（建议 `git mv`）。
- 虚拟 / 只读文件系统无法重命名（会提前拦下）。
- 默认接管 `Ctrl+Alt+Shift+R`（为此解绑了内置的「转到编辑器中的符号」）；
  若不想被接管，删掉 `keybindings.json` 里带 `-workbench.action.showAllSymbols` 的那条，
  或改用不冲突的 `Ctrl+Alt+P`。
